# SDK matrix report policy

`tools/sdk_matrix.py build` is the canonical SDK matrix build path. Each buildable
row must run `./tools/fw sdk-build-one <target>` and then evaluate the same log
with `tools/audit/sdk_warning_policy.py` against the matching
`EV_SDK_BUILD_TARGET` block.

A matrix row is `PASS` only when both values are true:

```text
build_status == PASS
warning_policy_status == PASS
```

The workflow uploads `logs/sdk/**` and `docs/release/sdk_build_matrix_report.md`
as CI artifacts. The matrix report generated by CI is artifact-only unless it is
explicitly committed by a release-preparation change. Release archives are built
from `HEAD`; therefore generated SDK matrix reports must not be silently created
or changed inside release gates without a subsequent secret-safe clean-tree
check.
